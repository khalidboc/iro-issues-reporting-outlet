## Project Overview

After a feasibility study, IRO (Issues Reporting Outlet) was designed as a simple digital channel that allows:

- AAUA students, and
- Indigenes/residents of the surrounding communities

to **report issues** (security, infrastructure, utilities, environment, academic facilities, health, transport, etc.) in a structured way.

## How to Run the Web App

1. Clone or download this repository.
2. Open `web/index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
3. No server or installation required. Data is stored in the browser’s localStorage.

Alternatively, the folder can be served with any static file server or published via GitHub Pages.

## Key Features (Prototype)

- Report an issue with category, location and optional anonymity
- View public list of submitted reports
- Basic live statistics
- Fully responsive (mobile-friendly)
- Clean attribution of student work
