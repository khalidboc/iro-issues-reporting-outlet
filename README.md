# IRO — Issues Reporting Outlet

CSC426 Weekly Dev, Weekend 3. Mini web outlet for AAUA students and indigenes of Akungba, Iwaro, Etioro, and Ayegunle.

Live mini page for the lecturer: open `docs/iro-standalone.html` in a browser (no install).

| Path | Brief item |
|---|---|
| `docs/iro-standalone.html` | Mini web interface (report, list, desk status) |
| `docs/SRS.md` | Software requirements specification |
| `docs/usecase.svg` and `docs/usecase.drawio` | Use-case diagram. Open the `.drawio` file in draw.io |
| `docs/ishikawa.svg` and `docs/ishikawa.drawio` | Ishikawa diagram |
| `docs/questionnaire.md` | Questions to paste into Google Forms |
| `docs/object-listing.md` | Object listing |
| `src/lib/iro.ts`, `src/routes/index.tsx` | Code listing for the React version |

Reports stay in the browser. There is no account, on purpose (sensitive reports, short deadline).

Form link: paste the Google Form URL here after you publish it.
